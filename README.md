# USALB Radio 24

A new 24/7 internet radio project.

## Project goals

- 24/7 automated music/radio playback
- Live microphone broadcasting
- Live shows and podcasts
- Browser-based radio player
- Station management and scheduling
- Separate development and production configuration

## Architecture

The project is designed to work with a dedicated radio server/streaming backend. The repository contains the configuration, web player, documentation, and deployment pieces; the actual audio stream will run on the radio server.
